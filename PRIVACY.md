# Privacy Policy for Universal Skills Extension

**Last Updated:** July 1, 2026

This privacy policy governs your use of the **Universal Skills** browser extension ("the Extension"). The Extension is designed to help you manage and inject custom markdown-based prompt templates ("skills") into various web-based AI interfaces locally.

### 1. Personal Information Collection and Usage
The Extension does not collect, store, or transmit any personally identifiable information, browsing history, or user data. 
* All of your imported markdown files, custom prompt templates, active states, and extension settings are stored strictly on your local machine using the browser's local extension storage (`chrome.storage.local`).
* No data is transmitted to our servers or any third-party analytics services.

### 2. External Network Communications
The Extension communicates with external domains strictly at your direction:
* **GitHub and GitHub Raw Domains:** If you choose to import a markdown skill template from a public or private GitHub repository URL, the Extension fetches that file directly from GitHub on your behalf. This interaction is direct between your browser and GitHub. No intermediate servers are used.
* **Supported AI Platforms:** The Extension injects controls into your active browser tabs for supported AI chat platforms (including ChatGPT, Claude, Gemini, Perplexity, Grok, DeepSeek, and Qwen) to allow local injection of prompt files. The Extension does not read or transmit your chat histories.

### 3. Data Security
Because all data remains on your local device, the security of your stored prompt templates and settings relies on the security protocols of your browser and local operating system.

### 4. Changes to This Privacy Policy
We may update this Privacy Policy from time to time. Any changes will be posted directly within the Extension repository. Your continued use of the Extension following the posting of changes constitutes your acceptance of those changes.

### 5. Contact
If you have any questions or suggestions about this Privacy Policy, please open an issue in the project repository.
